## 1. Что это за сайт

Сайт про деньги в Узбекистане: кредиты, вклады, карты, курсы валют, золотые слитки, переводы без комиссии, банкоматы на карте и
расчёт «какой кредит мне по силам». Первый экран — сразу дела, без приветствия: плитки «Взять кредит», «Открыть вклад» и так далее.

- **Адрес:** https://moliq-new-design.livops.app
- **Репозиторий:** `tisak559314-cloud/new-design-moliq`, ветка `main`. Livops собирает и выкладывает сайт после каждого пуша.
- **Данные** готовит проект `moliq` (папка `bankmap-next/scripts`, репозиторий `tisak559314-cloud/moliq`) и публикует в хранилище
  Vercel Blob. Сайт читает их оттуда сам — коммитить данные в этот репозиторий не нужно.
- **Языки:** русский, узбекский, английский. Язык — в адресе (`/uz/…`, `/en/…`), выбор запоминается.
- Старый сайт (`moliq/bankmap-next`, Next.js) больше не развивается; данные он получает те же.

## 2. Из чего он собран

Ванильный JavaScript (ES-модули) без фреймворка, один файл стилей, одна страница-оболочка. Библиотек в браузере нет, кроме карты
(MapLibre, подгружается только там, где карта есть на экране). Для сборки — esbuild и linkedom (только на компьютере и на Livops).

```
new-design/
├── index.html                 оболочка: шапка, место для страницы, подвал, нижняя панель
├── serve.py                   локальный сервер: исходники (python3 serve.py) или собранное (--dist)
├── package.json, livops.json  сборка: npm run build → dist/; Livops: npm ci → npm run build → dist
├── tools/
│   ├── build.mjs              сборка: код с хешами, данные, готовые страницы, sitemap, 404, _headers
│   ├── seo.mjs                заголовки и описания страниц на трёх языках, с числами из данных
│   └── og.html                картинка превью ссылок (assets/og.png) — как её перерисовать, написано в файле
├── assets/
│   ├── css/app.css            все стили (переменные в :root, в конце — телефон)
│   ├── js/main.js             запуск в браузере: маршруты, переходы без перезагрузки, клавиши, окна
│   ├── js/nav.js              адреса: язык в начале пути, короткие ссылки #/… → настоящие адреса
│   ├── js/app.js              интерфейс: шапка, меню языка, нижняя панель, подвал, поиск, сравнение
│   ├── js/lib.js              помощники: числа, значки, флаги, наклейки, поле суммы, аннуитет
│   ├── js/data.js             загрузка данных из хранилища и готовые выборки
│   ├── js/store.js            что человек уже ввёл: сумма, срок, вид платежей, сравнение
│   ├── js/i18n.js             переводы на узбекский и английский
│   ├── js/chart.js            график по дням с подсказкой
│   ├── js/mapkit.js           карта на MapLibre (банкоматы, мини-карта, отделения со слитками)
│   ├── js/views/*.js          страницы: home, catalog, rates, gold, transfers, check, map, banks, chat
│   ├── banks/                 логотипы банков
│   ├── og.png                 картинка превью ссылок 1200×630
│   └── icon.svg, moliq-logo.svg
└── work.md, alldone.md, README.md
```

**Оформление.** Серый холст `#f2f4f7`, белые карточки со скруглением 24 px, почти без теней. Шрифт один — Onest. Чёрный `#0a0b10` —
главное действие, лайм `#c8f24a` — сигнал («самая низкая ставка», выбранный раздел), синий `#2d5bff` — ссылки, янтарный — предупреждение.
Все значения — переменные в начале `app.css`. Точки перелома: 1100 px и 760 px (телефон).

## 3. Сборка и выкладка

`npm run build` запускает `tools/build.mjs` (~8 секунд):

1. **Код и стили.** esbuild собирает `main.js` со всеми страницами (каждая — отдельный кусок, грузится, когда нужна) и `app.css`
   в файлы с хешем содержимого в имени: `main-JV66TYFB.js`. Браузер хранит их год; новая версия получает новое имя, поэтому
   старое и новое не смешиваются. (Раньше это делал `stamp.py` руками перед каждым пушем — его больше нет.)
2. **Данные.** Скачивается манифест хранилища и восемь файлов, которые читает сайт; копия ложится в `dist/data/` — запас на случай,
   если у человека не откроется хранилище. Хранилище недоступно при сборке — сборка падает, и на хостинге остаётся прошлая версия.
3. **Готовые страницы.** Каждый адрес (54 штуки: разделы, виды кредитов, валюты, 34 банка) на трёх языках рисуется заранее тем же
   кодом, что в браузере (linkedom вместо браузера) — 162 страницы. У каждой свои `<title>`, описание, канонический адрес,
   ссылки на другие языки (`hreflang`), Open Graph для превью в Telegram (`assets/og.png`). Тексты — `tools/seo.mjs`, числа в них
   берутся из данных («Микрозаймы в банках Узбекистана: 166 предложений»). AI-чат закрыт от поиска (`noindex`).
4. **Служебные файлы.** `sitemap.xml` (156 адресов со ссылками на языки), `robots.txt`, `404.html` (на ней открывается любой адрес,
   которого нет среди готовых, — например, `/credits?bank=…`; дальше страницу рисует `main.js`), `_headers` (код и стили — кэш
   на год, данные — 5 минут, страницы — проверять каждый раз).

**В браузере** готовая страница видна сразу, а `main.js` тут же перерисовывает её на свежих данных из хранилища и оживляет кнопки.
Заголовок вкладки при первом заходе остаётся подробным (для поиска), при переходах внутри сайта — короткий.

**Выкладка:** `git push` в `main` → Livops выполняет `npm ci`, `npm run build` и выкладывает `dist/` (`livops.json`). Бесплатно —
40 сборок в месяц, поэтому данные в репозиторий не коммитятся: они идут мимо сборки, прямо из хранилища.

**Проверить локально:** `python3 serve.py` — исходники без сборки (для правок); `npm run preview` — собрать и открыть как на хостинге.

## 4. Каркас: адреса, шапка, поиск, языки

### Адреса

Чистые пути, язык — первым: `/credits/micro?amount=20000000&term=24`, `/uz/credits/micro`, `/en/credits/micro`. Русский — без
приставки. `nav.js` разбирает адрес (`parse`) и собирает его обратно (`href`). В коде страниц ссылки пишутся коротко —
`href="#/credits?bank=kapital"`, — а `localizeLinks` сразу превращает их в настоящие адреса текущего языка, поэтому любую ссылку
можно открыть в новой вкладке, переслать, и её видит поисковик.

`main.js` перехватывает нажатия на внутренние ссылки и меняет страницу без перезагрузки (History API), кнопка «Назад» работает.
Старые адреса с решёткой (`/#/rates/gold`) при заходе переводятся на чистые. Если человек раньше выбрал узбекский или английский,
главная `/` открывается сразу на этом языке (выбор — в `localStorage`, ключ `moliq-lang`).

| Адрес | Страница | Файл |
|---|---|---|
| `/` | Главная | `views/home.js` |
| `/credits`, `/credits/micro` (`consumer`, `auto`, `mortgage`, `edu`) | Кредиты | `views/catalog.js` |
| `/deposits`, `/cards` | Вклады, карты | `views/catalog.js` |
| `/transfers` | Переводы без комиссии | `views/transfers.js` |
| `/rates`, `/rates/EUR`, `/rates/RUB` | Курсы валют | `views/rates.js` |
| `/rates/gold` | Золотые слитки | `views/gold.js` |
| `/stocks`, `/stocks/<ТИКЕР>` | Акции Узбекистана, страница бумаги | `views/stocks.js` |
| `/map` | Банкоматы | `views/map.js` |
| `/check` | Что мне по силам | `views/check.js` |
| `/banks`, `/banks/complaints`, `/bank/<id>` | Банки, индекс жалоб, страница банка | `views/banks.js` |
| `/chat` | AI-чат | `views/chat.js` |

Параметры: `?amount=`, `?term=` (каталог и расчёт), `?bank=<id>` (каталог и карта), `?open=<id>` (открыть предложение), `?cur=USD`
(вклады), `?f=h24,cashIn` (фильтры карты), `?q=…` (вопрос в чат). Неизвестный адрес — «Страница не найдена» с кнопкой на главную.

### Шапка, нижняя панель, подвал

- **Меню:** Банки, Кредиты, Вклады, Переводы, Курсы валют, Акции, Банкоматы, Что мне по силам. «Карт» в меню нет —
  они открываются с главной и из поиска (решение Азама 25.11.2026).
- **Справа:** поиск и язык (флаг и код; меню — ссылки на эту же страницу на других языках). Кнопки «Войти» больше нет:
  вход был заглушкой.
- **На телефоне** внизу закреплена панель: Главная, Кредиты, Вклады, Курсы, Карта. Плавающая кнопка «AI-чат» — везде, кроме чата.
- **Подвал:** откуда данные и на какую дату, ссылки на «Банки», «Что мне по силам», «AI-чат», источник.

### Поиск

Лупа или Cmd/Ctrl+K. Ищет по банкам, кредитам, вкладам и картам; понимает запрос в любой раскладке и написании: «kapital»,
«капитал», «o‘zbek» и «ozbek» находят одно и то же (буквы сводятся к латинице, апострофы убираются). Стрелки выбирают, Enter открывает.

### Языки

Шаблоны написаны по-русски, `i18n.js` переводит готовую страницу: словарь `D` (строка → два перевода), шаблоны `R` (строки с числом),
`UNITS` (млн, сум, мес.), `E` — фразы с другим порядком слов (элемент с атрибутом `data-i18n` переводится целиком). Всё, что
появляется на странице позже, переводится само (`MutationObserver`); при сборке страница переводится целиком (`translateTree`).
Названия банков и продуктов не переводятся. **Новую строку интерфейса нужно сразу добавить в `D`** с узбекским и английским.

### Что запоминается

`store.js` (до закрытия вкладки): сумма и срок кредита, вид платежей, сумма и валюта вклада, ответы «Что мне по силам», слиток,
карты и сумма перевода, сравнение. Дольше живут только выбор языка и отметки «Уже переводил».

### Сравнение

Галочка «Сравнить» в подробностях предложения, до трёх одного вида; окно сравнения — таблица с подсветкой лучшего.

## 5. Страницы и фичи

### 5.1. Главная (`views/home.js`)

1. **Плитки дел.** «Взять кредит» с полем суммы (ввёл, нажал «Показать» — каталог уже с этой суммой) и виды кредитов чипами.
   «Открыть вклад», «Выбрать карту», «Обменять валюту», «Найти банкомат», «Перевести без комиссии», «Купить золото» —
   с числами из данных.
2. **Чёрная полоса** «Какой кредит вам по силам?».
3. **Курсы валют** — курс ЦБ, изменение за день, где дешевле купить и дороже продать.
4. **Лучшие предложения** — вкладки по категориям, по четыре карточки, одна на банк.
5. **Мини-карта** центра Ташкента (нажатие открывает большую карту с выбранными фильтрами) с банкоматами и чипами (Humo, Uzcard, Visa, Валюта, Пополнение, Круглосуточно). Данные —
   лёгкий файл `atms-home.json` (~180 КБ вместо 2,9 МБ всей карты): общее число, число банкоматов для каждого из 64 сочетаний
   чипов и точки центра Ташкента. Кнопка «Открыть карту» переносит фильтры на большую карту.
6. **«Спросите Moliq AI»** — ведёт в чат.

### 5.2. Кредиты, вклады, карты (`views/catalog.js`)

- **Сверху:** вид кредита / валюта вклада / платёжные системы карт.
- **Сумма и срок** — поле с готовыми суммами и чипы сроков; заранее ничего не подставлено.
- **Платежи: Равные / Убывающие** (только кредиты). Равные — аннуитет; убывающие — долг гасится равными частями, проценты на остаток:
  тогда в карточке «Первый платёж» (самый большой) и меньшая переплата. Формулы: аннуитет `annuity` в `lib.js`; убывающие —
  первый платёж `S/n + S·r`, переплата `S·r·(n+1)/2`, где `r` — ставка в месяц. Считается по верхней границе ставки.
- **Под списком одна строка:** у кредитов (когда есть расчёт) — «Без страховки и комиссий банка — полную стоимость кредита банк
  покажет до подписания договора»; у вкладов больше 200 млн сум (валютные — по курсу ЦБ) — «Государство гарантирует вклады
  до 200 млн сум в одном банке — большую сумму надёжнее разделить между банками» (закон ЗРУ-1031 от 18.02.2025).
- **Фильтры:** «Онлайн», «Без залога» (только если таких кредитов в данных не меньше пяти), «Целевые программы» (по умолчанию
  скрыты — дешевле, но не для всех), у вкладов — «Пополнение», «Снятие», «Капитализация», у карт — «Бесплатный выпуск», «В долларах».
- **Список** сгруппирован по банкам, метка «Самая низкая ставка» — только у обычных кредитов при сортировке по ставке.
- **«Подробнее»** — условия, «Условия на Bank.uz», «Сравнить»; `?open=<id>` открывает предложение и прокручивает к нему.

### 5.3. Курсы валют (`views/rates.js`)

Курс ЦБ и изменение за день, график за 30 дней, «Купить дешевле» и «Продать дороже», калькулятор обмена, таблица банков.
У таблицы — «Хочу: Купить / Продать»: «Купить» ставит первыми банки с самым дешёвым курсом продажи, «Продать» — с самым
дорогим курсом покупки; переключатель общий с калькулятором («Покупаю / Продаю»).

### 5.4. Золотые слитки (`views/gold.js`, `/rates/gold`)

- Вес 5–100 г, цена продажи ЦБ, выкуп (целая и повреждённая упаковка), сколько теряете при продаже сразу, «Мой слиток»
  (за сколько банк выкупит сегодня), цена 1 г у ЦБ и в мире, наценка.
- **«Где есть слитки»:** выбор области и веса, **карта отделений со слитками** выбранной области и таблица. Кнопка **«Маршрут»**
  открывает путь в Яндекс Картах. Координаты отделений находит `moliq` при сборе данных: отделение из таблицы ЦБ ищется среди
  отделений того же банка в той же области на карте банкоматов (сегодня найдено 82 из 124). Не найдено — вместо маршрута
  «Найти на карте» (поиск по названию в Яндекс Картах).

### 5.5. Переводы без комиссии (`views/transfers.js`)

- Выбор карт, сумма, чип «С карты любого банка».
- **План перевода:** сначала приложения с самым большим остатком лимита, сверх лимитов — где комиссия ниже; итог и «Сэкономите»
  против обычных 1,1% (Click, Payme).
- Если у приложения есть **лимит одного перевода** (`perTransfer`), план показывает, сколько переводов понадобится
  («3 перевода по 4 млн»), а в карточке метка «За один перевод до …». Если **сверх лимита комиссия берётся со всей суммы
  перевода** (`feeOnFull`) — янтарная метка: платную часть надо слать отдельным переводом.
- «Уже переводил» — остаток лимита в этом месяце (хранится в браузере). Закончившаяся акция скрывается сама.

### 5.6. Что мне по силам (`views/check.js`)

Четыре вопроса: вид кредита, доход, **кредиты и рассрочки** (сколько уже платите в месяц), сумма и срок. Ответ — сразу и с каждым
шагом точнее; «спокойно» — до 35% дохода на все платежи, больше половины банки не дают. Советы — кнопками, которые применяются сразу.

### 5.7. Банкоматы на карте (`views/map.js`, `mapkit.js`)

MapLibre, подложка OpenFreeMap в палитре Moliq. Точки цвета банка, ближе — логотипы. Фильтры, список ближайших, подсказка с
кнопкой «Маршрут» в Яндекс Картах, «Рядом со мной», ссылки `?bank=`, `?f=`. Сейчас 11 839 банкоматов и 1 940 отделений,
в том числе вернувшиеся Зарафшан (17) и Учкудук (4) — см. раздел 6.

### 5.8. Банки и индекс жалоб ЦБ (`views/banks.js`)

Карточки банков, вкладка «Индекс жалоб» (первая десятка за квартал), страница банка с плитками и курсами.

### 5.9. Акции Узбекистана (`views/stocks.js`, `/stocks`)

Справочный каталог, а не «топ для покупки» (по ТЗ «Акции Узбекистана»): что за компания, есть ли выпуск, торгуется ли бумага
и когда была последняя сделка.

- **Два списка:** «На бирже» — бумаги биржи «Тошкент» (котировальный лист, рейтинг ликвидности и бегущая строка цен, ~110),
  «Все АО» — все акционерные общества из Центрального депозитария (~700: ИНН, область, номинал, число акций, ISIN, статус).
- **Поиск** по названию, тикеру, коду бумаги, ИНН, ISIN; в любой раскладке. Ничего на бирже — предложит показать среди всех АО.
  Акции ищутся и в общем поиске сайта (лупа).
- **Фильтры:** отрасль (банки, промышленность, страхование, нефть и газ, телеком, транспорт, прочие), «Мои акции»
  (звёздочка, хранится в браузере), «Ещё фильтры» — обыкновенные / привилегированные, ликвидность по оценке биржи, сделки
  в последнюю сессию / за 7 дней, категория листинга (Premium, Standard, Приватизация, Транзит, вне котировального листа).
  Фильтры и сортировка — в адресе (`/stocks?sector=bank&sort=turnover`): «Назад» со страницы бумаги возвращает тот же список.
- **Порядок по умолчанию — «Сначала активные»:** свежая цена → рейтинг ликвидности биржи → оборот за 30 дней → дата сделки →
  тикер. Это не рекомендация (так и написано под списком). Ещё сортировки: оборот, сделки за месяц, рост и падение за день
  (только у бумаг с ценой последней сессии), изменение за месяц (с датой базы), недавние сделки, по алфавиту.
- **Цена всегда с датой.** Сделка старше недели — янтарная метка «Без сделок N дней», старше месяца — цена серая;
  изменение «за день» показывается только у бумаг, торговавшихся в последнюю сессию. Нет сделок — «—», а не ноль.
- **Страница бумаги:** цена и изменение к прошлой цене, «Последняя сделка: дата, время · биржа «Тошкент»», «Получено Moliq …».
  График по дням: 1Н–3Г и всё, цена или оборот. Ось — время: дни без сделок не рисуются как торговые (пропуск больше недели —
  пунктир и подпись «нет сделок N дн.», подсказка «Сделок не было, последняя цена … от …»). Ключевые показатели, официальная
  ликвидность и число сделок за месяц, «На что обратить внимание» (только факты: старая цена, редкие сделки, низкая
  ликвидность, вне котировального листа), «О компании» со ссылками на Openinfo и страницу биржи, другие акции компании.
- **«Где купить»** — окно без «Купить»: брокеры — члены биржи, реестр лицензий НАПП, Fondbozori.uz, «Как начать
  инвестировать»; тикер и код бумаги для заявки. Moliq сделок не проводит.
- Под каталогом и на странице бумаги — оговорка «не инвестиционная рекомендация» и источники (ссылка на uzse.uz обязательна).
- **Чего нет:** финансовой отчётности и дивидендов (Openinfo не даёт рабочего открытого API — только ссылка), заявок bid/ask,
  капитализации (число акций у депозитария и биржи расходится — знаменатель ненадёжен), уведомлений.

### 5.10. AI-чат (`views/chat.js`)

Пока не модель, а помощник по данным каталога: подбор кредита анкетой прямо в чате, курсы, вклады, банкоматы. Закрыт от поиска.

## 6. Данные: откуда, где лежат, как устроены

**Где лежат.** В хранилище Vercel Blob: каждый файл — под адресом с хешем содержимого (`data/catalog.<хеш>.json`, неизменный,
кэш на год), а список актуальных адресов — в манифесте `data/manifest.json` (кэш 60 секунд). Сайт (`data.js`) при заходе читает
манифест, затем нужные файлы; новые данные видны через несколько секунд после публикации, без пересборки. Хранилище не ответило —
берётся копия из `/data/<имя>.json`, положенная при сборке.

| Файл | Что в нём | Кто пользуется |
|---|---|---|
| `catalog.json` | 34 банка, 572 кредита, 175 вкладов, 355 карт | каталог, главная, поиск, чат, расчёт |
| `rates.json`, `rates-history.json` | курс ЦБ и курсы 29 банков, история по дням | курсы, главная, банк |
| `atms.json` | банкоматы и отделения (компактно: строка — массив, признаки — битовые маски) | карта, страница банка |
| `atms-home.json` | числа для чипов мини-карты и точки центра Ташкента | главная |
| `gold.json` | цены и остатки слитков (у отделения — координаты, если нашлось), мировая цена, история | золото, главная |
| `p2p.json`, `complaints.json` | лимиты переводов, индекс жалоб | переводы, главная, банки |
| `stocks.json` | бумаги биржи (цена, дата и время сделки, оборот за 30 дней, ликвидность) и все АО депозитария | акции, главная, поиск |
| `stocks/<ТИКЕР>.json` | цены по дням: `[дата, открытие, максимум, минимум, закрытие, акций, оборот]`, только дни со сделками | страница бумаги |

| Данные | Источник |
|---|---|
| Кредиты, вклады, карты, курсы банков | Bank.uz (не чаще одного запроса в 3 секунды) |
| Официальный курс | cbu.uz |
| Банкоматы и отделения | основа — выгрузка от 22.11.2026, поверх неё сайты 21 банка, пробелы — точки Bank.uz |
| Границы областей | geoBoundaries (OpenStreetMap, ODbL) — `moliq/bankmap-next/data/geo/uz-regions.json` |
| Слитки | cbu.uz (цены, остатки), gold-api.com (мировая цена) |
| Лимиты переводов, индекс жалоб | вручную по сайтам банков и публикации ЦБ |
| Акции | биржа «Тошкент» (uzse.uz: котировальный лист, цены, рейтинг ликвидности, история по дням; robots.txt — не чаще запроса в минуту), Центральный депозитарий (web.uzcsd.uz — все АО) |

**Области на карте — по границам.** Область точки определяется по полигонам областей (`moliq/.../scripts/regions.mjs`).
Точка дальше 30 км от своей области или вне страны считается ошибкой координат и убирается. Раньше мерили расстояние «больше 120 км
от центра области» — так пропадали целые города длинной Навоийской области. Новые точки с сайтов банков получают область по границам.
**Пробелы** основы заполняются точками Bank.uz там, где в 3 км нет ни одной точки (дубли в городах не появляются; у банков, чей
сайт отдаёт полный список, не заполняются — верим банку). Повторная сборка ничего не добавляет.

## 7. Как данные обновляются

Всё делает проект `moliq`; в этот репозиторий ничего не коммитится.

**Расписание в GitHub** (`moliq/.github/workflows/data-update.yml`):

| Когда (Ташкент) | Что |
|---|---|
| каждый день 10:40 и 16:40 | быстро: курсы, реестры, новости, новые продукты, база знаний, золото, переводы, акции (~8 страниц бумаг) |
| в ночь на понедельник и на четверг, 01:00 | полностью: ещё банкоматы с сайтов банков, статьи ЦБ, ~40 страниц акций |
| кнопкой «Run workflow» | любой режим |

Нужен секрет `BLOB_READ_WRITE_TOKEN` (есть). **Руками** то же — `moliq/scripts/update.sh` (`quick`, без режима — полное, `site` —
только золото и переводы, `only rates,gold` — выбранные шаги). Каждый набор перед публикацией проверяется (`check-data.mjs`):
не прошедший не публикуется, остальные публикуются. Отчёт — в сводке запуска и `bankmap-next/reports/`.

**Оповещения в Telegram** (`moliq/bankmap-next/scripts/notify-telegram.mjs`): сообщение в личный чат, если обновление упало,
шаг не удался, набор не прошёл проверку или есть «проверьте вручную» (одно и то же — не чаще раза в неделю). Всё хорошо — тишина.
Нужны секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (в GitHub и, для запуска с компьютера, в `bankmap-next/.env.local`);
без них оповещения молчат. Проверить: «Run workflow» с режимом `telegram` или `node scripts/notify-telegram.mjs --test`.

Шаги: `rates`, `registry`, `news`, `atms` (сайты банков → `build-atms.mjs`: пробелы из Bank.uz, проверка по границам,
`atms-home.json`), `products`, `knowledge`, `kb`, `gold` (`import-gold.mjs`, с координатами отделений), `p2p` (`import-p2p.mjs`:
проверка лимитов по страницам банков, напоминание про квартал индекса жалоб), `stocks` (`import-stocks.mjs`: листинг и цены
одной страницей, рейтинг ликвидности раз в 3 дня, страницы бумаг по кругу; биржа на графике заполняет дни без сделок нулевым
объёмом — такие дни отбрасываются; бумаг стало на 20% меньше — набор не публикуется).

## 8. Что обновляется руками

Файлы — в `moliq/bankmap-next/data/manual/`; после правки запустить `scripts/update.sh site` (или дождаться расписания).

**Лимиты переводов — `p2p.json`.** Когда отчёт предупредил «проверьте тариф»: поправить `limit`, `feeAfter`, фразу в `watch.has`,
дату `checkedAt`. Необязательные поля правила: `perTransfer` — больше этого за один перевод нельзя; `feeOnFull: true` — сверх
лимита комиссия со всей суммы перевода. Вносится только то, что банк называет сам; новое условие в `needs` — сразу в `i18n.js`.

**Индекс жалоб — `complaints.json`.** Раз в квартал по напоминанию: новая десятка, прежние значения — в `prev`.

**Обычная комиссия** для сравнения — `baseline` в `p2p.json` (сейчас 1,1%).

## 9. Чего на сайте нет и почему

- **Вход и личный кабинет** — нужен сервер; заглушка «Войти» убрана, чтобы не обещать того, чего нет.
- **Модель Moliq AI в чате** — чат пока отвечает по правилам (решение: оставить заглушкой до подключения модели).
- **Уведомления посетителям в Telegram** («слиток подешевел», «доллар дешевле 12 000») — нужен бот с сервером и подписками;
  оповещения о сбоях обновления для владельца — есть (раздел 7).
- **Отзывы о банках** — нужны сервер и модерация.
- **История цен слитков за прошлые годы** — у ЦБ нет архива, история копится с 24.11.2026.
- **Координаты всех отделений со слитками** — ЦБ даёт только названия; 42 из 124 не нашлись на карте, для них — поиск в Яндекс Картах.
- **Полная стоимость кредита (ПСК)** — банки не публикуют страховки и комиссии в одном виде; на сайте честная оговорка.
