## 1. Что это за сайт

Сайт про деньги в Узбекистане: кредиты, вклады, карты, курсы валют, золотые слитки, переводы без комиссии, банкоматы на карте и
расчёт «какой кредит мне по силам». Первый экран — сразу дела, без приветствия: плитки «Взять кредит», «Открыть вклад» и так далее.

- **Адрес:** https://moliq-new-design.livops.app
- **Репозиторий:** `tisak559314-cloud/new-design-moliq`, ветка `main`. Хостинг Livops пересобирает сайт сам после каждого пуша.
- **Локально:** `python3 serve.py`, затем http://localhost:4321.
- **Языки:** русский, узбекский, английский.
- **Основной сайт** (`moliq/bankmap-next`, https://moliq.antigradient.uz) — отдельный проект на Next.js. Новый сайт берёт у него
  готовые данные: каталог, курсы и карту.

## 2. Из чего он собран

Статический сайт без сборки и без сервера. Одна страница `index.html`, один файл стилей и скрипты-модули, которые браузер
загружает как есть. Библиотек нет, кроме карты (MapLibre, подгружается только на страницах с картой).

```
new-design/
├── index.html                 каркас страницы: шапка, место для содержимого, подвал, нижняя панель, карта импортов
├── serve.py                   локальный сервер на порту 4321 (отдаёт файлы без кэша)
├── stamp.py                   проставляет версии файлам в index.html — запускать перед каждым пушем кода
├── work.md                    этот файл
├── README.md                  короткий обзор
├── assets/
│   ├── css/app.css            все стили (19 разделов, в конце — телефон)
│   ├── js/app.js              каркас: шапка, маршруты, поиск, вход, язык, сравнение
│   ├── js/lib.js              общие помощники: числа, значки, флаги, наклейки, поле суммы
│   ├── js/data.js             загрузка данных и готовые выборки (лучший курс, типичная ставка)
│   ├── js/store.js            что человек уже ввёл: сумма, срок, язык, сравнение
│   ├── js/i18n.js             переводы на узбекский и английский
│   ├── js/chart.js            график по дням с подсказкой
│   ├── js/mapkit.js           карта банкоматов на MapLibre
│   ├── js/views/home.js       главная
│   ├── js/views/catalog.js    кредиты, вклады, карты
│   ├── js/views/rates.js      курсы валют
│   ├── js/views/gold.js       золотые слитки
│   ├── js/views/transfers.js  переводы без комиссии
│   ├── js/views/check.js      «Что мне по силам»
│   ├── js/views/map.js        банкоматы на карте
│   ├── js/views/banks.js      список банков, индекс жалоб ЦБ, страница банка
│   ├── js/views/chat.js       AI-чат
│   └── banks/                 логотипы банков
├── data/                      данные сайта, см. раздел 5
├── tools/
│   ├── gold.mjs               сбор цен и остатков золотых слитков
│   └── refresh.mjs            обновление всех данных нового сайта одним запуском
└── .github/workflows/data.yml расписание автообновления
```

**Оформление.** Серый холст `#f2f4f7`, белые карточки со скруглением 24 px, почти без теней. Шрифт один — Onest. Чёрный `#0a0b10` —
главное действие, лайм `#c8f24a` — сигнал («самая низкая ставка», выбранный раздел), синий `#2d5bff` — ссылки. Все значения лежат
переменными в начале `app.css` (`:root`). Точки перелома две: 1100 px и 760 px (телефон).

**Кэш и версии.** Livops отдаёт всё из `assets/` с кэшем на год. Чтобы вернувшийся посетитель получил новые файлы, `stamp.py`
дописывает к каждому файлу `?v=<хеш содержимого>`: стилям и главному скрипту — прямо в `index.html`, остальным модулям — через
карту импортов (`<script type="importmap">`). Файл не менялся — адрес тот же, браузер берёт его из кэша. Папка `data/` лежит
вне `assets/` и под этот кэш не попадает.

## 3. Каркас: шапка, маршруты, поиск, языки

Всё это — `assets/js/app.js`.

### Маршруты

Адрес страницы хранится после решётки: `#/credits/micro?amount=20000000&term=24`. Функция `route()` разбирает его на раздел
(`credits`), путь (`micro`) и параметры, загружает модуль страницы только когда он понадобился (`import("./views/…")`) и вызывает
его главную функцию с пустым узлом. Страница возвращает функцию «уборки» (остановить таймеры, снять карту) — она вызывается при
уходе. Если человек ушёл дальше, пока страница грузилась, устаревший ответ отбрасывается.

| Адрес | Страница | Файл |
|---|---|---|
| `#/` | Главная | `views/home.js` |
| `#/credits`, `#/credits/micro` (`consumer`, `auto`, `mortgage`, `edu`) | Кредиты | `views/catalog.js` |
| `#/deposits` | Вклады | `views/catalog.js` |
| `#/cards` | Карты | `views/catalog.js` |
| `#/transfers` | Переводы без комиссии | `views/transfers.js` |
| `#/rates`, `#/rates/USD` (`EUR`, `RUB`) | Курсы валют | `views/rates.js` |
| `#/rates/gold` | Золотые слитки | `views/gold.js` (его подгружает `rates.js`) |
| `#/map` | Банкоматы | `views/map.js` |
| `#/check` | Что мне по силам | `views/check.js` |
| `#/banks` | Все банки | `views/banks.js` |
| `#/banks/complaints` | Индекс жалоб ЦБ | `views/banks.js` |
| `#/bank/<id>` | Страница банка | `views/banks.js` |
| `#/chat` | AI-чат | `views/chat.js` |

Параметры, которые понимают страницы: `?amount=`, `?term=` (каталог и расчёт), `?bank=<id>` (каталог и карта), `?open=<id>`
(открыть конкретное предложение), `?cur=USD` (вклады), `?f=h24,cashIn` (фильтры карты), `?q=…` (вопрос в чат).

### Шапка, нижняя панель, подвал

- **Меню:** Кредиты, Вклады, Карты, Переводы, Курсы валют, Банкоматы, Что мне по силам (массив `NAV`).
- **На телефоне** меню скрыто, внизу закреплена панель из пяти разделов: Главная, Кредиты, Вклады, Курсы, Карта (`TABS`).
- **Справа в шапке:** поиск, выбор языка, «Войти».
- **Плавающая кнопка «AI-чат»** — на всех страницах, кроме самого чата.
- **Подвал:** откуда данные и на какую дату, ссылки на «Банки», «Что мне по силам», «AI-чат», источник.

### Поиск

Кнопка-лупа или Cmd/Ctrl+K открывает окно с одним полем. Ищет по названию банка, кредита, вклада и карты в уже загруженном
каталоге (`searchResults`), результаты — группами, не больше 4–5 в группе. Стрелки вверх и вниз выбирают строку, Enter открывает.
Пустое поле показывает «Часто ищут».

### Языки

Шаблоны написаны по-русски. Для узбекского и английского `i18n.js` заменяет готовый текст на странице:

- словарь `D` — русская строка целиком и два перевода;
- список шаблонов `R` — для строк с числом внутри («Показать ещё 12 из 30», «цена ЦБ на 24.11.2026»);
- `UNITS` — единицы («млн», «сум», «мес.», «г», «шт.»);
- `E` — фразы, где порядок слов в языках разный: переводится весь элемент с атрибутом `data-i18n`.

За страницей следит `MutationObserver`: всё, что появляется позже (подсказка на графике, новый список), переводится само.
Названия банков, продуктов и отделений не переводятся — они такие же, как в источнике. Новую строку нужно добавить в `D`,
иначе на узбекском и английском она останется русской.

### Что запоминается

`store.js` хранит в `sessionStorage` (до закрытия вкладки) то, что человек ввёл: сумму и срок кредита, сумму и валюту вклада,
ответы «Что мне по силам», выбранный слиток, карты и сумму перевода, список сравнения и язык. Поэтому сумма, введённая на главной,
уже стоит в каталоге, а из каталога переходит в расчёт. Единственное, что живёт дольше, — отметки «Уже переводил» (раздел 4.5).

### Сравнение

В подробностях любого предложения есть галочка «Сравнить». Можно набрать до трёх предложений одного вида; внизу появляется полоса
«В сравнении: 2 · Сравнить». Окно сравнения показывает таблицу, лучшее значение в строке подсвечено (ниже ставка, больше сумма,
дешевле выпуск).

### Вход

Окно «Вход» с полем телефона есть, но это заглушка: по кнопке показывается сообщение, что вход подключится позже. Сервера у сайта нет.

## 4. Страницы и фичи

### 4.1. Главная (`views/home.js`)

Сверху вниз:

1. **Плитки дел.** Большая «Взять кредит» с полем суммы: ввёл число, нажал «Показать» — попал в каталог уже с этой суммой.
   Под полем — виды кредитов чипами. Малые плитки: «Открыть вклад» (самая высокая ставка в сумах), «Выбрать карту» (сколько карт),
   «Обменять валюту» (курс доллара ЦБ), «Найти банкомат» (сколько их на карте). Третий ряд — две широкие плитки:
   «Перевести без комиссии» (самый большой лимит, который годится для любой пары карт Uzcard и Humo) и «Купить золото»
   (цена слитка 5 г). Все числа в плитках считаются из данных, а не вписаны руками.
2. **Чёрная полоса** «Какой кредит вам по силам?» с кнопкой «Проверить».
3. **Курсы валют** — три карточки (доллар, евро, рубль): курс ЦБ, изменение за день, «Купить дешевле» и «Продать дороже» с названием банка.
4. **Лучшие предложения** — вкладки: вклады, вклады в долларах, микрозаймы, автокредиты, ипотека, карты. По четыре карточки,
   не больше одной от банка. Кредиты — по самой низкой верхней ставке, целевые программы не участвуют; карты — с бесплатным выпуском.
5. **Мини-карта** — настоящая карта центра Ташкента с банкоматами. Чипы (Humo, Uzcard, Visa, Валюта, Пополнение, Круглосуточно)
   меняют точки и счётчик, а кнопка «Открыть карту» переносит выбранные фильтры на большую карту. Карта не двигается, чтобы в ней
   не застревала прокрутка страницы, и загружается только когда до неё доскроллили.
6. **«Спросите Moliq AI»** — поле вопроса и три готовых вопроса, ведут в чат.

### 4.2. Кредиты, вклады, карты (`views/catalog.js`)

Один модуль на три раздела; что показывать, он понимает по адресу.

**Сверху:**
- у кредитов — переключатель вида: Все, Микрозаймы, Потребительские, Автокредиты, Ипотека, Образовательные;
- у вкладов — валюта: в сумах, в долларах, в евро;
- у карт — платёжные системы чипами.

**Блок суммы и срока** (кроме карт). Поле «Сколько вам нужно» с готовыми суммами под вид кредита и чипы сроков. Сумма заранее
не подставлена: без неё список показывает ставку, сумму и срок, а с суммой и сроком — ставку, платёж в месяц и переплату.

**Как считается:**
- платёж по кредиту — аннуитет по **верхней** границе ставки (`annuity` в `lib.js`); если ставка диапазоном, подпись «Платёж до»;
- переплата — платёж × срок − сумма;
- доход по вкладу — с капитализацией сложные проценты по месяцам, без неё простые.

**Фильтры чипами:** «Онлайн», «Целевые программы», у вкладов — «Пополнение», «Снятие», «Капитализация», у карт —
«Бесплатный выпуск», «В долларах». Справа — выбор банка и сортировка. Когда включён хоть один фильтр, появляется «Сбросить».

Два правила честности:
- **«Без залога»** показывается, только если в данных хотя бы пять кредитов этого вида, где банк прямо пишет, что обеспечение
  не нужно. Иначе чипа нет: фильтр по тому, чего в данных почти нет, вводил бы в заблуждение.
- **Целевые программы** (для бизнеса, молодёжи, фермеров и т. п.) по умолчанию скрыты: они дешевле, но даются не всем. Признака
  в данных нет, они узнаются по названию (`TARGETED_RE` в `data.js`).

**Список.** Предложения сгруппированы по банкам: видно лучшее предложение банка, остальные — под кнопкой «Ещё N от банка».
Показывается по 12 банков, дальше «Показать ещё». Первая строка получает лаймовую метку «Самая низкая ставка» (или «Самая
высокая» у вкладов) — только при сортировке по ставке и только у обычных кредитов.

**«Подробнее»** раскрывает условия: сумма, срок, обеспечение, первый взнос, погашение, документы, требования, а также ссылку
«Условия на Bank.uz», галочку «Сравнить» и дату обновления. Кнопка «В банк» есть, только если известна страница продукта на сайте банка.

**Прямая ссылка** `?open=<id>` открывает предложение, прокручивает к нему и держит его в списке при любых фильтрах — так работают
переходы из поиска, чата и «лучших предложений».

### 4.3. Курсы валют (`views/rates.js`)

- **Переключатель:** USD, EUR, RUB и «Золото» (четвёртая вкладка ведёт на страницу слитков).
- **Большая цифра** — официальный курс ЦБ и изменение за день (красный рост, зелёное снижение).
- **График за 30 дней** (`chart.js`). Отвечает на курсор, палец и стрелки клавиатуры: над точкой появляется дата, курс в этот день
  и насколько он выше или ниже сегодняшнего.
- **Две плашки:** «Купить дешевле» и «Продать дороже» — лучший курс среди банков и название банка.
- **«Сколько получится»** — калькулятор справа: «Покупаю» или «Продаю», сумма в валюте, ответ в сумах по лучшему курсу с названием банка.
- **Таблица «Курсы в банках»** — банк, курс покупки, курс продажи; лучшие значения подсвечены лаймом. Сортировка — где дешевле купить.

Таблица подстраивается под данные: переключатель «в отделении / в приложении / в банкомате» появляется, только если в данных
больше одного способа обмена, а колонка «Обновлено» — только если у банков есть время обновления.

### 4.4. Золотые слитки (`views/gold.js`, адрес `#/rates/gold`)

Страница повторяет устройство страницы курса.

- **Вес слитка:** 5, 10, 20, 50, 100 г. Выбор запоминается.
- **«Купить в банке»** — цена продажи ЦБ на дату. Когда в истории накопится два дня, рядом появится изменение и график.
- **«Банк выкупит»** — цена обратного выкупа в целой упаковке, отдельно — в повреждённой (после экспертизы).
- **«Если продать сразу, потеряете»** — разница между ценой покупки и выкупа в сумах и в процентах от цены.
- **«Мой слиток»** — вводите, сколько заплатили, и видите: за сколько банк выкупит сегодня и на сколько вы в плюсе или в минусе.
- **Три плитки:** цена 1 г в слитке ЦБ, цена 1 г на мировом рынке (цена унции ÷ 31,1034768 × курс доллара ЦБ) и наценка ЦБ
  к мировой цене в процентах. Если мировая цена не загрузилась, вторая и третья плитки не показываются.
- **«Где есть слитки»** — таблица отделений банков с числом слитков каждого веса. Выбор области (по умолчанию Ташкент) и чипы веса:
  с выбранным весом остаются только отделения, где он есть, а его колонка подсвечивается. На телефоне таблица превращается
  в пять плашек в ряд под названием отделения.
- **«Найти на карте»** открывает Яндекс Карты с поиском по банку, отделению и области. Свою булавку мы не ставим: ЦБ даёт
  название отделения без адреса и координат.

### 4.5. Переводы без комиссии (`views/transfers.js`, адрес `#/transfers`)

Отвечает на вопрос: в каком приложении перевести с карты на карту без комиссии и что делать, если сумма больше лимита.

- **Выбор карт:** с какой (Uzcard, Humo) и на какую. Кнопка со стрелками меняет их местами.
- **Сумма** с готовыми суммами: 1, 3, 5, 10 млн. Без суммы виден просто список приложений по величине лимита.
- **Чип «С карты любого банка»** — по умолчанию выключен. Включённый оставляет только приложения, где банк **прямо** пишет, что
  переводить можно с карты любого банка. Там, где банк этого не уточняет, мы за него не решаем.
- **План перевода** появляется, когда введена сумма (функция `plan`):
  - сначала берутся приложения с самым большим остатком лимита — так частей получается меньше всего;
  - хватает одного — «Хватит одного приложения»; нужно несколько — «Разбейте перевод на части» со списком, сколько через какое;
  - если бесплатных лимитов не хватает, остаток идёт туда, где комиссия сверх лимита ниже, и показывается её сумма;
  - справа — итоговая комиссия и «Сэкономите»: сравнение с обычной комиссией 1,1% (столько берут Click и Payme).
- **Карточка приложения:** логотип, банк и название, «Без комиссии в месяц — до N», «Сверх лимита — N%» (прочерк, если банк
  не называет), дата проверки, кнопка «Тариф» со ссылкой на источник. Метки: «Нужна карта банка», «Нужна идентификация»,
  «Акция до …» и другие условия.
- **«Уже переводил»** — отмечаете, сколько перевели в этом месяце через приложение. Остаток лимита показывается полоской и
  учитывается в плане. Отметки хранятся только в браузере (`localStorage`, ключ `moliq-nd-p2p-used`) и обнуляются с началом месяца.
- **Закончившаяся акция.** Приложение, у которого срок акции (`promoUntil`) прошёл, сайт перестаёт показывать сам.

Сейчас в списке 12 приложений: Alliance Pay, BRB, Ipoteka Mobile, Openbank, Hamkor, Mavrid, Davr Mobile 2.0, Milliy, MyTuron,
HUMO Pay, Paynet, alif mobi.

### 4.6. Что мне по силам (`views/check.js`)

Расчёт нагрузки по доходу. Четыре вопроса слева, ответ справа.

1. Какой кредит. 2. Доход в месяц. 3. Другие кредиты (нет / есть и сколько плачу). 4. Сумма и срок.

**Суммы не обязательно печатать:** у каждого поля кнопки «−» и «+» (шаг растёт вместе с числом, при удержании число бежит само),
добавки «+500 тыс.», «+1 млн», «+5 млн» и крестик очистки.

**Ответ появляется сразу и уточняется с каждым шагом:**
- введён только доход — «Вам по силам» и строка на каждый срок: до какой суммы и какой платёж. Нажатие на строку подставляет сумму и срок;
- есть сумма, нет срока — как эта сумма ложится на каждый срок: «По силам», «Впритык» или «Тяжело»;
- есть всё — вердикт, шкала нагрузки с отметками 35% и 50%, расчёт строками (доход, платежи по другим кредитам, новый платёж,
  остаётся на жизнь) и кнопка «Показать N предложений».

**Правила расчёта:**
- платёж считается по типичной ставке — медиане верхних ставок обычных кредитов этого вида из каталога;
- «спокойно» — когда на все кредиты уходит до 35% дохода; больше половины банки не дают;
- если не по силам, совет даётся кнопками, которые сразу применяются: «Срок 3 года» или «Сумма 15,7 млн» — то, при чём расчёт проходит.

На телефоне ответ оказывается ниже полей, поэтому над нижней панелью держится строка с коротким выводом; нажатие прокручивает к ответу.
Расчёт можно передать ссылкой: `#/check?type=micro&income=8000000&other=1000000&amount=20000000&term=24`.

### 4.7. Банкоматы на карте (`views/map.js`, `mapkit.js`)

- **Карта** — MapLibre 4.7.1, подгружается только на страницах с картой. Подложка — стиль OpenFreeMap «Positron», перекрашенный
  в палитру Moliq, с подписями на русском (`moliqMapStyle`).
- **Точки.** При мелком масштабе — цветные точки цвета банка, ближе (с масштаба 13,5) — значки-логотипы банков. Значки рисуются
  на лету из логотипов (`bankPin`).
- **Фильтры слева:** банк и чипы — Humo, Uzcard, Visa, Mastercard, Круглосуточно, Пополнение, Валюта. Под ними счётчик.
- **Список** — до 40 ближайших банкоматов в видимой части карты (или ближайших к вам) с расстоянием. Нажатие приближает карту и
  открывает подсказку.
- **Подсказка:** банк, название, адрес, метки, платёжные системы и кнопка «Маршрут» — открывает Яндекс Карты с путём до точки;
  если вы дали геопозицию, поле «откуда» заполняется само.
- **«Рядом со мной»** запрашивает геопозицию, ставит метку и приближает карту.
- Ссылка `#/map?bank=kapital` открывает карту только с этим банком, `?f=h24,cashIn` — с включёнными фильтрами.

Данные лежат в `atms.json` в сжатом виде: банкомат — массив из девяти значений, признаки и платёжные системы — битовые маски.
Поэтому 11,7 тысячи точек занимают 2,8 МБ и фильтруются мгновенно.

### 4.8. Банки и индекс жалоб ЦБ (`views/banks.js`)

- **`#/banks`** — карточки всех банков по алфавиту: сколько у банка кредитов, вкладов и карт.
- **`#/banks/complaints`** — вкладка «Индекс жалоб». Первая десятка банков за квартал: место, банк, полоска, значение и изменение
  к прошлому кварталу (рост красным, снижение зелёным). Пояснение одной строкой: выше 1 — на банк жалуются чаще, чем у него
  клиентов. Внизу — сколько всего жалоб пришло в ЦБ и ссылка на публикацию.
- **`#/bank/<id>`** — страница банка: плитки «Кредиты», «Вклады», «Карты», «Банкоматы» с числами и переходом в каталог или на карту
  уже с этим банком, курсы валют банка. Если банк есть в индексе жалоб, под плитками появляется блок с его значением.

Индекс — это доля жалоб на банк, делённая на его долю клиентов. ЦБ называет только первую десятку и не считает индекс,
если жалоб за квартал меньше ста, поэтому у остальных банков блока нет.

### 4.9. AI-чат (`views/chat.js`)

Пока это не модель, а встроенный помощник по данным каталога: он узнаёт тему вопроса по ключевым словам.

- **Про кредит** — показывает прямо в чате короткую анкету: вид кредита, сумма, срок. После «Подобрать предложения» анкета
  сворачивается в строку от имени человека, а помощник отвечает тремя карточками с самой низкой ставкой (по одной от банка):
  ставка, платёж, переплата. Целевые программы в подбор не входят.
- **Про курс** — курс ЦБ, где дешевле купить и где дороже продать.
- **Про вклад** — три самые высокие ставки в сумах (с учётом слова «пополнение»).
- **Про банкомат и карту** — ссылки на карту и каталог карт.

Модель Moliq AI подключается отдельно; сейчас на любой другой вопрос помощник честно отвечает, что умеет только это.

## 7. Как данные обновляются: update.sh

`moliq/scripts/update.sh` — одна команда, которая обновляет и основной сайт, и новый.

```bash
scripts/update.sh quick     # быстро, около 10 минут: курсы, реестры, новости, новые продукты, база знаний
scripts/update.sh           # всё, 1–1,5 часа: ещё банкоматы с сайтов банков, статьи ЦБ, давно не проверявшиеся продукты
scripts/update.sh deep      # как полное, но страницы всех продуктов перечитываются заново, около 3,5 часа
scripts/update.sh site      # только новый сайт, около минуты: золото, проверка лимитов переводов, индекс жалоб
scripts/update.sh only rates,news       # только выбранные шаги
scripts/update.sh full --skip=products  # всё, кроме выбранных
```

| Флаг | Что делает |
|---|---|
| `--no-push` | всё обновить и показать, что изменилось, но ничего не публиковать |
| `--no-site` | основной сайт обновить, новый не трогать |
| `--git` | после публикации ещё сохранить данные основного сайта коммитом |
| `--places-min=N` | дополнительно N минут обходить страницы банкоматов Bank.uz (карта из них не собирается) |

### Что происходит по шагам

1. **Проверки до начала.** Node 22 или новее, ключи публикации в `bankmap-next/.env.local`, доступность Bank.uz, ЦБ и основного сайта.
   Второе обновление параллельно не запустится (файл-замок), Mac не уснёт, пока идёт импорт.
2. **Скачать опубликованное** (`publish-data.mjs pull`). Обновление начинает с того, что сейчас на сайте: шаг, который не сработает,
   оставит опубликованные данные, а не старые из папки.
3. **Импорт** (`update-all.mjs`) — шаги по очереди:

   | Шаг | Что делает | Скрипты | В быстром режиме |
   |---|---|---|---|
   | `rates` | курсы банков и ЦБ, история | `import-rates.mjs` | да |
   | `registry` | реестры МФО и ломбардов | `import-registries.mjs` | да |
   | `news` | новости с сайтов банков | `bank-news.mjs` | да |
   | `atms` | банкоматы и отделения с сайтов банков поверх нынешней карты | `bank-atms.mjs`, `build-atms.mjs` | нет |
   | `products` | кредиты, вклады, карты | `import-products.mjs`, `bank-products.mjs`, `products-normalize.mjs` | да, только новые страницы |
   | `knowledge` | профили банков, статьи и FAQ ЦБ | `import-knowledge.mjs` | нет |
   | `kb` | база знаний помощника | `build-kb.mjs` | да |

   Шаг упал — его файлы откатываются к прежним, остальные шаги идут дальше.
4. **Проверка каждого набора** (`check-data.mjs`): курсы, каталог, карта, реестры, новости, база знаний. Например, если предложений
   стало заметно меньше, чем было, набор считается подозрительным и не публикуется; остальные публикуются.
5. **Публикация основного сайта** (`publish-data.mjs`). Файлы уходят в хранилище Vercel Blob, сайт отдаёт их через `/api/data`
   и видит новые данные сразу, без коммита и пересборки.
6. **Новый сайт** (функция `site_update`). Запускается `new-design/tools/refresh.mjs`, затем изменения в `new-design/data`
   коммитятся и пушатся — Livops пересобирает сайт сам. Сбой здесь не отменяет остальное. С `--no-push` изменения остаются в папке.
7. **Отчёт** — в консоли и в `bankmap-next/reports/update-ГГГГ-ММ-ДД.md`: что обновилось, насколько свежее, что изменилось.

В режиме `site` выполняются только шаг 1 (без проверки ключей) и шаг 6, причём каталог, курсы и карта не переносятся —
обновляется только своё: золото, проверка лимитов переводов, напоминание про индекс жалоб.

### Что делает `tools/refresh.mjs`

```bash
node tools/refresh.mjs --from=../moliq/bankmap-next/public/data [--skip=rates.json]   # так его вызывает update.sh
node tools/refresh.mjs --from-site=https://moliq.antigradient.uz                      # так его вызывает расписание в GitHub
node tools/refresh.mjs --from-site=https://moliq.antigradient.uz --copy-only          # только забрать опубликованное
```

1. **Каталог, курсы, история, карта.** Копируются из папки основного сайта (`--from`) или скачиваются из опубликованного на нём
   (`--from-site`). Файл, не прошедший проверку основного сайта (`--skip`), не переносится. Карта без адресов или с малым числом
   точек не принимается. Файл не изменился — не перезаписывается.
2. **Золото** — запускается `tools/gold.mjs`:
   - страница цен ЦБ: пять слитков, цена продажи и две цены выкупа;
   - страница остатков: область, банк, отделение, сколько слитков каждого веса;
   - курс доллара ЦБ и мировая цена унции;
   - в историю дописывается сегодняшний день (повторный запуск в тот же день заменяет запись);
   - запросы к ЦБ идут по одному с паузой; если таблица не разобралась (разметка изменилась), файл не перезаписывается;
   - мировая цена не ответила — остаётся прошлое значение со своей датой.
3. **Переводы без комиссии.** Лимиты скрипт не меняет. Для каждого приложения с полем `watch` он открывает страницу банка
   (с учётом `robots.txt`, раз в секунду) и ищет на ней фразу с числом:
   - фраза на месте — дата «Проверено» обновляется на сегодня;
   - фразы нет — предупреждение «на странице больше нет „10 млн“ — проверьте тариф», данные остаются прежними;
   - акция кончается в ближайшие 14 дней или уже кончилась — предупреждение;
   - запись не проверялась больше 45 дней — предупреждение.
4. **Индекс жалоб.** Только напоминание: если прошло три недели после конца следующего квартала, скрипт пишет, что ЦБ уже должен
   был опубликовать новый индекс.

С ключом `--copy-only` выполняется только первый шаг. Скрипт ничего не публикует сам: коммит и пуш делает `update.sh` или расписание.

## 8. Автообновление в GitHub

Запускать `update.sh` руками не обязательно: то же самое делают два расписания.

### Основной сайт — `moliq/.github/workflows/data-update.yml`

| Когда | Что |
|---|---|
| каждый день в 10:15 по Ташкенту | `scripts/update.sh quick --no-site` |
| в ночь на понедельник, 01:00 по Ташкенту | `scripts/update.sh --no-site` (полное) |
| кнопкой «Run workflow» | любой режим: quick, full, deep; галочку публикации можно снять — тогда только проверка |

- Нужны два секрета репозитория: `BLOB_READ_WRITE_TOKEN` и `DATA_PUBLISH_TOKEN` (те же значения, что в `bankmap-next/.env.local`).
  Расписание само убирает из них лишнее — кавычки, пробелы, префикс `ИМЯ=` — и меняет местами, если они перепутаны.
- Запуски идут строго по одному. Уже скачанные страницы Bank.uz хранятся между запусками в кэше GitHub; для самого первого
  запуска в репозитории лежит их копия (`bankmap-next/data/raw-seed.tgz`).
- Отчёт обновления виден в сводке запуска на вкладке Actions.

### Новый сайт — `new-design/.github/workflows/data.yml`

| Когда | Что |
|---|---|
| каждый день около 11:00 по Ташкенту | полное: `node tools/refresh.mjs --from-site=https://moliq.antigradient.uz` |
| каждые два часа с 07:40 до 21:40 по Ташкенту | лёгкое: то же с `--copy-only` — только забрать, что опубликовал основной сайт |
| кнопкой «Run workflow» | полное |

- Ключи не нужны. Изменения в `data/` коммитит бот `moliq-data-bot`.
- Лёгкая проверка нужна, потому что основной сайт публикует когда угодно; без неё новый сайт отставал бы до следующего утра.
- Коммит появляется, только если данные изменились: каждый коммит — это пересборка на Livops, а у него есть лимит сборок в месяц.
- Предупреждения («проверьте тариф», «акция кончается») видны в сводке запуска.

Если расписание работает, запускать `update.sh` на своём компьютере не нужно. Если всё же запускаете — не около 10:15 и не в ночь
на понедельник: два обхода Bank.uz одновременно нарушат его ограничение на частоту запросов.

## 9. Что обновляется руками

### Лимиты переводов — `data/p2p.json`

Когда скрипт предупредил «проверьте тариф» или вы сами узнали о новом лимите:

1. Откройте страницу банка из поля `source` и найдите новое число.
2. Исправьте `limit` (в сумах) и, если банк называет комиссию сверх лимита, `feeAfter`.
3. Поправьте фразу в `watch.has` — она должна встречаться на странице банка дословно («10 млн», «3 000 000»).
4. Поставьте сегодняшнюю дату в `checkedAt`.
5. Закоммитьте и запушьте файл.

Чтобы добавить приложение, скопируйте любую запись и заполните поля из таблицы в разделе 5. Правило одно: вносится только то, что
названо в официальном источнике; чего банк не называет, остаётся `null`. Условие в `needs` — это строка, которую видит человек;
новую строку нужно добавить и в словарь `i18n.js`, иначе на узбекском и английском она останется русской.

### Индекс жалоб — `data/complaints.json`

Раз в квартал, когда скрипт напомнил: возьмите новую десятку из публикации ЦБ, перенесите нынешние значения в `prev`, обновите
`quarter`, `period`, `prevPeriod`, `total`, `prevTotal` и ссылки.

### Обычная комиссия для сравнения

Поле `baseline` в `p2p.json` (сейчас 1,1% — Click и Payme). Изменят тариф — поправьте число.

## 10. Как выкладывать правки кода

```bash
python3 serve.py        # посмотреть на http://localhost:4321
python3 stamp.py        # проставить версии файлам — перед каждым пушем кода
git add -A && git commit -m "…" && git push
```

- `stamp.py` обязателен, если менялись файлы в `assets/`: без него у тех, кто уже заходил, смешаются старые и новые скрипты.
- При обновлении одних только данных `stamp.py` не запускается: версии нужны только файлам из `assets/`.
- Новая строка интерфейса — сразу в словарь `i18n.js` с переводами на узбекский и английский.
- Коммиты в этот репозиторий — от имени владельца, без подписей о соавторстве.

## 11. Чего на сайте нет и почему

- **Отзывы о банках с ответами банков.** Нужен сервер со входом, хранением и модерацией. Сайт статический, а пустая форма обещала
  бы то, чего он не делает.
- **Уведомления в Telegram** («слиток подешевел», «лимиты обновились») — по той же причине.
- **«Комиссия изменилась? Сообщить»** — некуда принимать сообщения.
- **Булавки отделений со слитками на карте.** У ЦБ нет адресов и координат отделений, только названия; вместо булавки наугад —
  поиск в Яндекс Картах.
- **История цен слитков за прошлые годы.** У ЦБ нет архива; история копится с 24.11.2026 по одному дню.
- **Настоящий вход и модель Moliq AI.** Окно входа — заглушка, чат отвечает по правилам, а не моделью.
- **Автообновление лимитов переводов.** Тарифы банков написаны в свободной форме на разных сайтах; скрипт умеет только заметить,
  что число со страницы исчезло.
- **Банкоматы Зарафшана, Учкудука и Томди.** В основе карты их нет: правило отсева «дальше 120 км от центра области», вероятно,
  убрало их ещё при старой выгрузке. Причина не проверялась.
