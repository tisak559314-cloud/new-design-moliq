# Moliq — новый дизайн

Сайт про кредиты, вклады, карты, курсы валют и банкоматы банков Узбекистана.
Статический сайт без сборки: HTML, один файл стилей и ES-модули. Данные лежат в папке data.

Сайт: https://moliq-new-design.livops.app — выкладывается сам при каждом пуше в main.

## Запуск

    python3 serve.py

Откройте http://localhost:4321

Подойдёт и любой другой статический сервер: корень сайта — эта папка, главный файл — index.html.

## Страницы

- Главная — плитки разделов, курсы валют, лучшие предложения, мини-карта
- Кредиты, вклады, карты — каталог с суммой, сроком, фильтрами и сравнением
- Курсы валют — курс ЦБ, банки, калькулятор обмена
- Золотые слитки (в «Курсах валют») — цена и выкуп слитков ЦБ, потеря при продаже, мировая цена, остатки по отделениям банков
- Переводы без комиссии — в каком приложении лимит больше, как разбить сумму, учёт уже использованного лимита
- Банки — список и индекс жалоб ЦБ за квартал
- Что мне по силам — расчёт нагрузки по доходу
- Банкоматы — карта с фильтрами и маршрутом
- AI-чат — пока встроенный помощник по данным каталога; модель Moliq AI подключается отдельно
- Языки: русский, узбекский, английский

## Данные

Условия банков и курсы банков — с [Bank.uz](https://bank.uz) (у каждого продукта ссылка на его страницу там), официальный курс — ЦБ (cbu.uz).
Файлы в data — снимок на дату, указанную в подвале сайта.

| Файл | Что в нём | Откуда |
|---|---|---|
| `gold.json` | цены слитков ЦБ, остатки по отделениям, мировая цена, история по дням | `node tools/gold.mjs`: cbu.uz (цены, остатки, курс доллара) и gold-api.com (цена унции) |
| `p2p.json` | бесплатные лимиты переводов с карты на карту по приложениям | ведётся вручную по тарифам банков; у каждой записи ссылка на источник и дата проверки |
| `complaints.json` | индекс жалоб ЦБ по банкам за квартал | ведётся вручную по публикации ЦБ (раз в квартал) |

Истории цен слитков у ЦБ нет: `tools/gold.mjs` дописывает один день за запуск, график на сайте появится со второго дня.
Что человек отметил в «Уже переводил», хранится только в его браузере и обнуляется с началом месяца.

## Обновление сайта

1. Данные — копии `catalog.json`, `rates.json`, `rates-history.json`, `atms.json` из `moliq/bankmap-next/public/data` в папку `data`;
   золото — `node tools/gold.mjs` (раз в день, после 10:30: ЦБ обновляет остатки утром).
2. Перед каждым пушем: `python3 stamp.py`. Хостинг хранит файлы из `assets` в кэше браузера год, поэтому скрипт дописывает
   к ним версии (`?v=хеш`) в `index.html`; без этого у тех, кто уже заходил, смешаются старые и новые файлы.
3. Пуш в `main` — сайт обновится сам.
