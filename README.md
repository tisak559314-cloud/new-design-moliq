# Moliq — новый дизайн

Сайт про кредиты, вклады, карты, курсы валют, золото, акции, переводы и банкоматы банков Узбекистана — на русском, узбекском и английском.

- **Сайт:** https://moliq-new-design.livops.app — Livops сам собирает и выкладывает его после каждого пуша в `main`.
- **Данные:** сайт читает их прямо из хранилища (Vercel Blob) при каждом заходе; их публикует `moliq/scripts/update.sh`
  и расписание в GitHub. Коммитить данные сюда не нужно.
- **Подробно** обо всём — в [work.md](work.md), что изменилось в последней большой переделке — в [alldone.md](alldone.md).

## Запуск

```bash
python3 serve.py            # исходники как есть: http://localhost:4321
npm ci && npm run preview   # собрать как на хостинге и открыть собранное: http://localhost:4321
```

Нужны Python 3 и Node 22 (`.nvmrc`). Сборка скачивает данные из хранилища, поэтому нужен интернет.

## Адреса

Язык — в начале адреса: `/credits` (русский), `/uz/credits`, `/en/credits`. Старые ссылки вида `/#/credits` переводятся сами.

| Адрес | Страница |
|---|---|
| `/` | главная |
| `/credits`, `/credits/micro` (`consumer`, `auto`, `mortgage`, `edu`) | кредиты |
| `/deposits`, `/cards` | вклады, карты |
| `/transfers` | переводы без комиссии |
| `/rates`, `/rates/EUR`, `/rates/RUB`, `/rates/gold` | курсы валют и золотые слитки ЦБ |
| `/stocks`, `/stocks/<ТИКЕР>` | акции Узбекистана: бумаги биржи «Тошкент» и все АО, страница бумаги с графиком |
| `/map` | банкоматы и отделения на карте |
| `/check` | что мне по силам |
| `/banks`, `/banks/complaints`, `/bank/<id>` | банки, индекс жалоб ЦБ, страница банка |
| `/chat` | AI-чат (пока помощник по данным каталога, не модель) |

## Сборка

`npm run build` (`tools/build.mjs`) собирает сайт в `dist/`:

- код и стили — одним файлом с хешем в имени (кэш браузера на год, новая версия — новое имя);
- каждая страница на трёх языках рисуется заранее со своим заголовком, описанием, картинкой превью и ссылками на другие языки —
  поисковики и Telegram видят готовый текст; в браузере страница сразу оживает и берёт свежие данные;
- `sitemap.xml`, `robots.txt`, `404.html`, `_headers`, копия данных в `dist/data/` на случай, если хранилище не ответит.

Livops делает то же сам (`livops.json`). Правка кода: проверить на `python3 serve.py`, закоммитить, запушить.
